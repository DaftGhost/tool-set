# 工具集

这是一个按工具组织的多语言仓库。每个工具可以独立运行，并按实际需要使用前端、后端、命令行入口或多种语言。

## 当前状态

当前仓库只有基础骨架，尚未选定语言、框架、包管理器或部署方式。新增工具时，在该工具目录内确定和记录这些选择。

## 目录

- tools/<tool-name>/：独立工具。一个工具需要前端、后端或多种语言时，在自己的目录内组织。
- docs/：跨工具的产品说明、设计决策和运维文档。
- packages/<package-name>/：仅在多个工具确实复用同一实现时创建。

## 添加工具

1. 在 tools/ 下为工具创建一个简短、稳定的目录名。
2. 在工具目录添加 README，说明用途、入口、输入输出、运行环境、配置方式和实际可用的开发命令。
3. 将语言清单、依赖、锁文件和构建配置放在对应工具内，不要求其他工具采用同一技术栈。
4. 前端与后端只有在确实分别开发、运行或部署时才拆目录；否则保持简单。
5. 只有出现具体的跨工具复用时才抽取共享包，并在共享包 README 说明其使用者和接口。
