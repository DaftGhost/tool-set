# LLM API 成本计算器

用于估算一次模型调用的输入、缓存与输出成本，并比较不同价格方案。页面适配手机、平板和桌面浏览器；方案只保存在当前浏览器，不需要账号或后端。

## 功能

- 编辑输入 Token 数、缓存命中率、输出/输入比例，以及缓存输入、未缓存输入和输出单价；也可从 models.dev 选择模型并载入只读单价。
- 在人民币（CNY）和美元（USD）之间切换；单价、成本拆分、方案比较和图表统一显示所选币种。
- 获取最新日度 USD/CNY 参考汇率，并显示数据日期；支持页面打开时、每 12 小时和手动刷新。
- 即时显示缓存与未缓存 Token 数量、输入成本、输出成本和总成本。
- 复制、命名、选择和删除价格方案，按当前输入量标记最低成本方案。
- 按缓存命中率、输入 Token 数或输出/输入比例绘制成本曲线；可切换总成本、输入成本和输出成本，拖动位置检查各方案成本。
- 标出曲线的成本交叉点；选中交点后查看对应参数下的各方案成本。
- 将方案草稿和当前方案写入浏览器 `localStorage`。没有云同步或真实模型调用。

## 计算约定

- 输入 Token 以百万 Token（M）录入；价格字段以当前显示币种录入，内部统一换算成人民币（CNY）后计算。
- USD 显示使用当前缓存的 USD/CNY 日度参考汇率；切换币种会同步换算方案单价和所有成本展示，不修改 Token 数量、比例或方案名称。
- models.dev 目录提供 USD / 百万 Token 单价。选择模型后，方案名会自动填入厂商与模型名，缓存输入、未缓存输入和输出单价按当前 USD/CNY 汇率换算并锁定；清除模型关联后保留数值并恢复手动编辑。厂商/模型来源与美元原价保存在方案中，汇率刷新会更新关联方案的人民币单价。
- models.dev 由社区维护，不保证与厂商价目同步；无单独缓存读取价格时，本工具按输入单价估算缓存输入。请以 models.dev 与厂商实际计费为参考，不将目录数据视为实时计费承诺。
- 输出 Token 数 = 输入 Token 数 × 输出/输入比例。
- 缓存输入成本 = 输入 Token 数 × 缓存命中率 × 缓存输入单价。
- 未缓存输入成本 = 输入 Token 数 × (1 − 缓存命中率) × 未缓存输入单价。
- 输出成本 = 输出 Token 数 × 输出单价；总成本为输入成本与输出成本之和。
- 输入值必须是非负数字，缓存命中率为 0–100%。表单在计算入口将 M 和百分比转换成有明确单位的数值；不完整或无效的值显示在对应字段，不参与成本计算。
- 本工具展示估算值，不适配各供应商可能存在的最小计费单位、分段定价、阶梯折扣或额外费用。

## 本地数据与错误处理

- 方案、币种选择和汇率快照存放在当前浏览器的 `localStorage`，不上传或同步到其他设备。获取汇率时只向 Frankfurter 公共 API 请求 USD/CNY 汇率；载入模型目录时向 models.dev 获取公共模型与价格数据，不发送方案或价格数据。
- 汇率使用 Frankfurter 的最新工作日参考数据，可能一天仅更新一次，不是分钟级行情。请求失败时继续使用本地缓存并标出数据日期；尚无缓存时可继续使用 CNY，USD 切换会在汇率获取成功后开放。
- 恢复草稿时会检查版本、数据结构、字段类型和方案数量；无法识别的已存数据不会在打开页面时被覆盖。用户编辑后，新草稿才会保存。
- 如果浏览器禁用了本地存储或写入失败，页面保留当前会话数据并提示无法持久保存。
- 添加方案会复制当前方案；最多保存 16 个方案，至少保留一个。

## 技术栈与目录

- TypeScript、Vue 3 Composition API、Vite；页面样式为原生 CSS，图表为原生 SVG。
- 纯计算模块不访问浏览器或网络；外部汇率响应和本地存档分别由 `services/` 与 `storage/` 边界校验。
- `src/domain/`：计算、方案约定和图表曲线。
- `src/services/`：获取并校验外部 USD/CNY 汇率和 models.dev 模型目录。
- `src/storage/`：localStorage 读取、校验与保存。
- `src/components/`：输入控件、成本拆分、方案对比和 SVG 图表。

## 运行

需要 Node.js 24.12 或更高的 24.x 版本。

~~~sh
npm install
npm run dev
~~~

## 构建与静态检查

~~~sh
npm run typecheck
npm run build
npm run preview
~~~

`build` 先进行 Vue/TypeScript 类型检查，再生成部署用静态文件到 `dist/`。
