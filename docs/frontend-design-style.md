# 全局前端设计风格：鼠尾草绿分析工作台

本文定义工具集的全局前端设计风格，适用于工具目录页与各工具页面。各页面按自己的使用流程组织内容，统一采用这里的配色、字体角色、视觉层次和交互表达。

## 风格定位

整体气质是低饱和、安静、紧凑、重视数据阅读。灰绿背景承托浅色面板，深绿色结果区域形成视觉重点；界面围绕选择、编辑、比较展开。

## 配色

| 配色角色 | 固定色值 | 用途 |
|---|---|---|
| 页面背景 | `#E9ECE5` | 灰绿底色 |
| 面板背景 | `#FAFBF7` | 主要内容区域 |
| 正文 | `#202820` | 标题、主要文字 |
| 次级文字 | `#6F796D` | 标签、说明 |
| 主色 | `#4C7053` | 选中状态、强调、主要交互 |
| 深色强调 | `#2E4333` | 核心结果、强选中状态 |

陶土色 `#B85F42` 和黄铜色 `#A67D39` 用于区分数据与提示状态，保持小面积使用。边框使用 `#D4DBD1`。

## 字体与排版

- 文字采用无衬线字体（sans-serif），沿用 `Avenir Next`、`PingFang SC`、`Microsoft YaHei`、系统字体的顺序。
- 金额、参数和单位采用等宽字体（monospace），沿用 `SFMono-Regular`、`Consolas`、`Liberation Mono`。
- 标题清晰有力，整体左对齐。主标题桌面字号为 30–46px，区块标题为 14–19px。
- 说明文字保持紧凑，具体字号以可读性为准。

## 布局

内容居中，最大宽度 1240px。按任务划分面板，编辑区域与结果区域紧邻。

内容顺序按页面的主要任务与操作流程安排。

响应布局（responsive layout）在 860px 以下将主要区域改为单列，在 560px 以下将表单进一步纵向排列，保留信息顺序。

## 形状与层次

主要面板圆角 14px，内部区域约 8–9px，控件约 5–7px。使用细边框和低透明度阴影，面板间距约 18px，内部留白约 24–26px。

深绿色实心区域突出最重要的结果；其余区域保持浅色。选中状态通过绿色边框和浅绿底色表达。

## 交互与文案

状态变化采用约 150ms 的轻量过渡，尊重减少动态效果设置。按钮直接说明动作，提示说明当前状态及下一步。

## 复用说明

> 采用全局「鼠尾草绿分析工作台」风格：灰绿背景、浅色面板、森林绿强调，搭配无衬线文字与等宽数据。采用左对齐、按任务分区的紧凑布局，以分级圆角、细边框和弱阴影建立层次。用深绿色区域突出核心结果，以克制的状态反馈和直接的操作文案支持使用。
